# vision — 적재 영상 분석 (미구현)

기획서 17·22장: 카메라/녹화 영상을 분석해 물품 수·유형·구역·변화를 **관측 결과(시각·근거·불확실성 포함)**로 backend에 전달하는 별도 Python 프로세스.

원칙
- API 요청 안에서 무거운 분석을 실행하지 않는다. 결과만 backend에 전달하고 업무 확정은 backend Service가 한다.
- 관측과 확정을 구분한다. 관측만으로 배송 완료·물품 신원을 확정하지 않는다.
- 시연 입력이 녹화 영상이면 결과에 출처를 남기고 화면에 표시한다.
- 원본 영상을 외부 AI로 보내는지, 보관 기간·삭제 방식을 구현 시 이 문서에 기록한다.
